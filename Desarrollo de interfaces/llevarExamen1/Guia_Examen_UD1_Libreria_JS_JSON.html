1. Visión general del ejercicio
Hay que construir una pequeña web de librería con dos entidades (libro y género). Un libro pertenece a un género
(libro.idgenero apunta a genero.idgenero). La aplicación permite crear libros y listar los de un género en
una pestaña nueva con tarjetas de Bootstrap.

2.1 Qué revisar antes de escribir una línea
•       Estructura de la plantilla: orden de carga de scripts (ajax.js antes que objetos.js antes que codigo.js; por eso
        codigo.js puede usar todo lo anterior).
•       Ids del HTML: mnuCrearLibro, mnuListado, frmCrearLibro, frmListado, txtTitulo,
        txtAutor, txtDescripcion, txtImagen, lstGenero, btnCrearLibro, btnListado. Fíjate:
        lstGenero está repetido en los dos formularios (ver trampas).
•       Formato del JSON: toda respuesta del servidor es {ok, mensaje, datos}. Con ok = false, datos es null.
•       Nombres exactos de columnas: idlibro, idgenero, titulo, autor, descripcion, imagen y
        idgenero, genero. Las claves de tu toJSON() deben coincidir al milímetro: el PHP las lee con
        $libro->idgenero.
•       Requisitos literales: qué se muestra con alert, cuándo se resetea el formulario, texto exacto del título, pestaña
        nueva.
•       Casos límite: género sin libros, error de servidor, apóstrofos en los datos, nombre de género con espacios o
        tildes.

3. Guía paso a paso
Apartado A: objetos.js (2 puntos)
Paso A.1: clases Libro y Genero
Qué hacer: una clase por entidad con un atributo privado (#campo) por cada columna, constructor que los recibe
en el orden de la tabla, getter y setter por atributo y toJSON().
    class Libro {
      #idlibro; #idgenero; #titulo; #autor; #descripcion; #imagen;

        constructor(idlibro, idgenero, titulo, autor, descripcion, imagen) {
          this.#idlibro = idlibro;      this.#idgenero = idgenero;
          this.#titulo = titulo;        this.#autor = autor;
          this.#descripcion = descripcion; this.#imagen = imagen;
        }

        get titulo() { return this.#titulo; }
        set titulo(valor) { this.#titulo = valor; }
        // ... mismo patron get/set para idlibro, idgenero, autor, descripcion, imagen

        toJSON() {
          return { idlibro: this.#idlibro, idgenero: this.#idgenero, titulo: this.#titulo,
                   autor: this.#autor, descripcion: this.#descripcion, imagen: this.#imagen };
        }
    }

    class Genero {                       // identica idea, solo 2 campos
      #idgenero; #genero;
      constructor(idgenero, genero) { this.#idgenero = idgenero; this.#genero = genero; }
      get idgenero() { return this.#idgenero; }   set idgenero(v) { this.#idgenero = v; }
      get genero() { return this.#genero; }       set genero(v) { this.#genero = v; }
      toJSON() { return { idgenero: this.#idgenero, genero: this.#genero }; }
    }

Por qué así: los campos con # son realmente privados; solo se alcanzan por los getters/setters. Como
JSON.stringify solo ve propiedades públicas, un objeto con todo privado se serializaría como {}. Por eso
existe toJSON(): JSON.stringify la detecta y usa lo que devuelve. Al crear un libro nuevo, idlibro va a
null porque la BD lo genera (AUTO_INCREMENT).

    TRAMPA Getter que se llama a sí mismo
    Si el atributo privado se llamase igual que el getter (por ejemplo, get titulo() { return this.titulo; }) entras
    en recursión infinita y obtienes Maximum call stack size exceeded. Dentro del getter siempre this.#titulo.


Paso A.2: la clase gestora (3 métodos)
Qué hacer: cada método empaqueta los parámetros en un FormData, llama a peticionGET/POST de ajax.js y
devuelve la respuesta tal cual ({ok, mensaje, datos}). La clase no toca el DOM: eso es cosa de codigo.js.
    class Libreria {          // el enunciado la llama GestorNotas: usa el nombre que te pidan
      async crearLibro(oLibro) {
        let datos = new FormData();
        datos.append("libro", JSON.stringify(oLibro));       // objeto JS -> string JSON
        return await peticionPOST("crear_libro.php", datos);
      }
      async getLibrosGenero(idgenero) {
        let datos = new FormData();
        datos.append("idgenero", idgenero);                  // llega a PHP en $_GET["idgenero"]
        return await peticionGET("get_libros_genero.php", datos);
      }
      async getGeneros() {
        return await peticionGET("get_generos.php", new FormData());    // FormData vacio
      }
    }

•    POST con JSON: el objeto completo viaja como un solo campo de texto (libro) y PHP lo reconstruye con
     json_decode($_POST["libro"]).
•    GET con parámetro: peticionGET recorre el FormData y añade cada par a la query string de la URL.
•    Son async porque fetch es asíncrono: devuelven una Promesa. Quien las llame necesita await.

    TRAMPA FormData vacío en getGeneros
    peticionGET hace for (let [clave, valor] of parametros). Si pasas undefined, lanza TypeError:
    parametros is not iterable. Aunque no haya parámetros, pasa new FormData().

 function mostrarFormulario(oEvento) {
   oEvento.preventDefault();               // los <a href="#"> saltarian al inicio de la pagina
   ocultarFormularios();                   // siempre primero: garantiza que no se vean a la vez
   switch (oEvento.target.id) {
     case "mnuCrearLibro": cargarDesplegables(); frmCrearLibro.classList.remove("d-none"); break;
     case "mnuListado":    cargarDesplegables(); frmListado.classList.remove("d-none");    break;
   }
 }

 function ocultarFormularios() {
   frmCrearLibro.classList.add("d-none");
   frmListado.classList.add("d-none");
 }

 async function cargarDesplegables() {
   let respuesta = await oLibreria.getGeneros();
   if (respuesta.ok) {
     let options = "";
     for (let genero of respuesta.datos) {
       options += `<option value="${genero.idgenero}">${genero.genero}</option>`;
     }
     frmCrearLibro.lstGenero.innerHTML = options;    // se rellenan LOS DOS desplegables
     frmListado.lstGenero.innerHTML = options;
   } else {
     alert("No se han podido cargar los generos: " + respuesta.mensaje);
   }
 }

Por qué así: la plantilla oculta los formularios con la clase de Bootstrap d-none (display: none). Mostrar =
classList.remove("d-none"); ocultar = classList.add("d-none"). El patrón ocultar todo y luego
mostrar uno es más seguro que alternar con toggle, porque no depende del estado previo. En cada <option>,
el value es el idgenero (lo que enviamos a la BD) y el texto visible es el nombre del género.

  TRAMPA Dos elementos con el mismo id
  En index.html existen dos id="lstGenero" (uno por formulario). document.getElementById("lstGenero")
  devuelve solo el primero, así que el segundo desplegable se quedaría vacío. Accede a través del formulario:
  frmListado.lstGenero (los controles de un form se buscan por su atributo name, que sí es único dentro de cada form).


  TRAMPA Paréntesis en el listener
  addEventListener("click", procesarAltaLibro()) ejecuta la función al registrar el evento, no al hacer click. Se
  pasa la referencia a la función, sin paréntesis.

Qué viaja por la red: JSON.stringify(oLibro) invoca tu toJSON() y produce algo como:
    {"idlibro":null,"idgenero":"5","titulo":"Dune","autor":"Frank Herbert",
     "descripcion":"...","imagen":"https://..."}

•       select.value siempre es un string ("5", no 5). Para el servidor da igual, pero si te piden número usa
        Number(...).
•       El botón es type="button", no submit, así que la página no se recarga y no necesitas preventDefault
        aquí.

    TRAMPA Olvidar el await
    Sin await, respuesta es una Promesa: respuesta.mensaje sale undefined y respuesta.ok también (nunca
    resetea el formulario). Toda función que use await debe ser async.


    TRAMPA Resetear siempre
    El enunciado exige que en caso de error no se haga ninguna acción y el formulario conserve los datos. Un reset()
    fuera del if (respuesta.ok) pierde puntos.



Apartado B.3: listado en pestaña nueva (2,5 puntos)
Es el apartado más largo porque intervienen dos páginas. Divídelo en tres mini-pasos:

Paso B.3.1: en codigo.js, abrir la pestaña pasando los datos por la URL
    function procesarListado() {
      let lst = frmListado.lstGenero;
      let idgenero = lst.value;                                                // id para consultar
      let genero = lst.options[lst.selectedIndex].textContent;                 // nombre para el titulo

        open("tarjetas.html?idgenero=" + encodeURIComponent(idgenero) +
             "&genero=" + encodeURIComponent(genero));             // open() = pestana nueva
    }

Por qué: una pestaña nueva es otra página con su propio JavaScript; la forma sencilla de pasarle información es
la query string (?clave=valor&clave2=valor2). encodeURIComponent protege nombres como «Ciencia
ficción» o «Ficción épica» (espacios, tildes, &...).

  Un let o const en el nivel superior de un script no se convierte en propiedad de window. Con let oLibreria,

  oLibreria. Además, si abres tarjetas.html directamente (sin pasar por index), opener es null.


Paso B.3.3: construir las tarjetas
El servidor devuelve los libros con el nombre del género (la consulta hace un JOIN: SELECT l.*, g.genero
...), por eso cada fila trae idlibro, idgenero, titulo, autor, descripcion, imagen y genero. Se
recorre el array y se acumula el HTML de cada tarjeta en un string; al final se vuelca una sola vez con
innerHTML.
 let cards = "";
 for (let libro of respuesta.datos) {
   cards += `<div class="col-12 col-md-4 col-lg-3 mb-3">
               <div class="card h-100" style="width: 15rem;">

7. Variantes probables de examen (para practicar)
Si dominas este ejercicio, un examen parecido cambiará las entidades o añadirá una función. Entrena estas
variantes:
•   Añadir un tercer campo al formulario (por ejemplo año) y propagarlo: clase, toJSON, lectura en B.2 y tarjeta.

    de index.html).
•   Validar campos obligatorios antes de enviar (si falta título, alert y no se llama al servidor).

    row-cols-md-3 row-cols-lg-4 en el .row.
